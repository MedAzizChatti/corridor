# Corridor

Corridor is an AI dispatcher for logistics: a simulated fleet, a tool-using agent whose write actions are proposals that a human approves, and evals that measure it. Built in public as a learning and portfolio project.

Docs: [`docs/`](docs/) — start with [`docs/STATUS.md`](docs/STATUS.md), the decisions in [`docs/decisions/`](docs/decisions/), and the milestone in [`docs/milestones/M1.md`](docs/milestones/M1.md).
