# 0020. Project name: Corridor

- **Date:** 2026-11-22
- **Status:** Accepted

## Context
The project needs a public name before the first commit. The working title, "FlowState", is already used by other products and projects, so it's ambiguous and hard to search for.

## Decision
The project is named **Corridor** (repository `corridor`). A *freight corridor* is a main route that goods flow along, which points directly at routes, maps and disruptions.

## Alternatives considered
- **Keep "FlowState"** — ambiguous and crowded.
- **Relay, Waypoint** — kept as backups.

## Consequences
- Renamed before the first commit, so there's no history to rewrite.
